# Changelog

## 1.1.2-preview — 2026-10-28

- Add a prominent one-click Mad God's Overhaul workflow: detect the active profile, scan, build defaults, approve successful results and export a separate folder and ZIP.
- Keep shooting-hand selection visible above both the MGO shortcut and generic batch workflow.
- Add bounded installation discovery, an installation chooser and Locate MGO fallback, plus a direct ZIP download.
- Report and exclude unsupported meshes and failed defaults; retain source/profile validation and protect existing editor work before replacing it.

## 1.1.1-preview — 2026-10-28

- Make the recommended three-step batch build the first workflow on the page.
- Build and validate all supported meshes with defaults, then approve successful results together and generate output.
- Exclude and list failed defaults/unsupported files without blocking successful results.
- Move individual review and adjustment into an optional collapsed section.

## 1.1.0-preview — 2026-10-28

- Read-only bow discovery from active MO2 profiles or deployed game Data, including mod-added bows and BSA assets.
- Left/right handedness, synchronized 3D previews, adjustable openings, per-shape controls and local saved projects.
- Batch selection, filtered select-all, opening presets, preview cards, approval, inclusion and skipping.
- Separate mesh-only folder/ZIP output, reviewed-byte validation and source-change detection.
- Profile validation tolerates identical bookkeeping-file rewrites and MO2 UI saves while detecting actual profile/resource changes.

## 1.0 — 2026-10-26

- Initial release of bow sight windows for Skyrim VR.
- Left- and right-handed choices through a FOMOD installer.
- Vanilla/DLC bow families, Bound Bow and unique-model variants in the reference setup, covering 34 mesh paths per hand.
- Mesh-only changes with existing grip, arrow placement, skeletons, materials, collision and original weight tables retained.
- Source toolkit, neutral-shaded comparison image, credits and Nexus preparation materials. Bundled meshes remain local pending upstream redistribution permissions.
