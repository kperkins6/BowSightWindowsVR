# Changelog

## 1.0 — 2026-10-26

- Initial release of bow sight windows for Skyrim VR.
- Left- and right-handed choices through a FOMOD installer.
- Vanilla/DLC bow families, Bound Bow and unique-model variants in the reference setup, covering 34 mesh paths per hand.
- Mesh-only changes with existing grip, arrow placement, skeletons, materials, collision and original weight tables retained.
- Source toolkit, neutral-shaded comparison image, credits and Nexus preparation materials. Bundled meshes remain local pending upstream redistribution permissions.
