# Bow Sight Windows VR 0.3.0 — source and tools

This release publishes the original portable builder, bounded NIF editor, left/right FOMOD configuration, tests, credits and Nexus preparation materials.

The mod's locally installed 0.3.0 meshes have a wider remaining section (approximately 40% over 0.2.0) and an opening shortened by 15%, with the existing arrow shelf fixed. Both handed sets cover 34 mesh paths in the reference MGO installation.

**Download contents:** source/tools and documentation only. The attached SourceToolkit ZIP contains no NIF, BSA, DDS, game files or private telemetry. It is not an install-ready mesh mod. The bundled mesh FOMOD remains local pending upstream redistribution permissions, as requested by the author.

The builder requires the user's own exact reference source meshes and Python 3.10+. It checks every generated mesh against verified 0.3.0 output hashes, then creates a local FOMOD. See the README for usage, compatibility limits and testing scope.

Nexus description/BBCode, credits, a comparison image and a permission/upload checklist are included for the eventual mesh release.
