# Bow Sight Patcher 1.1.2 preview

MGO users can choose their shooting hand and click **1-click MGO build** at the top of the page. The shortcut detects the active MO2 profile, discovers bows, builds defaults, approves validated results and exports a separate mod folder and ZIP. Failed defaults and unsupported layouts are excluded and reported.

Use **Locate MGO** if automatic discovery misses your installation. Multiple detected installations require a choice. **Download MGO ZIP** retrieves the completed archive for installation through MO2.

Other mod lists keep the recommended three-step batch workflow and optional individual editor. The patcher requires Python 3.11+ and a WebGL browser. Extract the source package and run **Start Patcher.cmd**.

Public downloads contain source, tools and documentation only. Generated meshes remain local. Original assets, MO2 installation state and load order are unchanged.
