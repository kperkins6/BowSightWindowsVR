Bow Sight Windows VR 1.0

Install the locally generated FOMOD ZIP through Mod Organizer 2.
Choose exactly one handedness:
  Left-handed: bow in RIGHT hand, string drawn with LEFT hand.
  Right-handed: bow in LEFT hand, string drawn with RIGHT hand.
Reinstall and replace the mod to switch hands.

Covers vanilla Skyrim, Dawnguard and Dragonborn bow families, Bound Bow,
Drainspell Bow and unique-model variants used by the reference MGO setup.
There are 34 mesh paths per hand, including first-person and display variants.
Crossbows and NPC-only dummy props are excluded.

Only visual meshes are installed. Keep the matching texture/material mods.
Let this package win conflicts with other bow mesh providers and PGPatcher
output. Disable it to restore the underlying meshes. No ESP, ESL or DLL is
included, and there are no aiming, damage or ballistics changes.

Public GitHub downloads contain source/tools only. Mesh archives remain
local pending upstream redistribution permissions. See the repository's
credits and asset-permissions document before redistributing generated files.
