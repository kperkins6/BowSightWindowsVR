# Bow Sight Windows VR 1.0

Give Skyrim VR bows a clear sight window above the arrow shelf. Choose left- or right-handed meshes through a FOMOD installer.

- Vanilla Skyrim, Dawnguard and Dragonborn bow families, Bound Bow and unique-model variants in the reference setup.
- 34 mesh paths per hand, including relevant first-person and display variants.
- Mesh-only changes: existing grip and arrow placement, source skeletons, collision, animation references and materials stay intact. No aiming, damage or ballistics changes.
- New comparison image: uncut bow versus sight window, using the same bow, view and scale.

**Public download: source and tools only.** The SourceToolkit ZIP contains the portable builder, bounded NIF editor, FOMOD configuration, tests, documentation and Nexus preparation materials. It contains no NIF, BSA, DDS, game files or telemetry and is not an install-ready mesh mod.

The builder requires Python 3.10+ and the user's own exact reference source meshes, then produces a verified local FOMOD. The bundled mesh archive remains local pending upstream redistribution permissions, as requested by the author.

See the README for build instructions and compatibility. Nexus BBCode, credits and an upload checklist are included.
